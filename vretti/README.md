# Vretti Keep Ready prototype

This experimental monitor holds a CoreBluetooth connection to one selected Vretti D463B and reads its standard model-number characteristic every minute. It does not write print commands, change printer settings, or print. If disconnected, it scans again. A bounded foreground run exits at the requested duration.

Build with `zsh vretti/build.sh`. Then run the executable in `.build-vretti/VrettiKeepReady.app/Contents/MacOS/` with the Mac's CoreBluetooth peripheral UUID and a duration in seconds (30–86,400). The UUID is local to the Mac and should be obtained from a scan; do not guess between devices with the same name. Once verified, `python3 vretti/keep-ready.py install --id UUID` installs a login helper. Use `status` to see recent checks and `uninstall` to stop and remove its login entry. Uninstall leaves the app and logs in place.

The previous Bluetooth printer probe observed service `180A` and readable model characteristic `2A24`. A read is a connection check; whether it resets the printer's auto-off timer is unknown. A second client connected and sent a test image while the prototype was connected; physical output and longer idle behavior require verification. Client apps should retrieve the known peripheral by identifier, since an already connected printer may stop advertising. The Mac must remain awake, and the monitor cannot wake a powered-off printer. The build script alone does not install a login service.
